# Contributing

Run `npm install`, `npm test`, and `python3 -m unittest discover -s test -p 'test_python.py'`. Keep the core domain-neutral and runtime dependency-free. Add regression tests for interval indexing, graph semantics and data-contract changes. Follow the browser acceptance checklist in docs/VALIDATION.md for interaction changes. Do not contribute proprietary SDK source, restricted examples, real customer datasets or credentials. Implement from openly stated requirements with independently written code.
