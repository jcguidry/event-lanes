# Changelog

## 0.2.0 — 2026-10-01

- Add agent onboarding, architecture/data guides, recipes, troubleshooting, runnable JS/TS/global and Python/DataFrame examples, and cold-start exercise.
- Stack overlapping detail events by lane and prioritize noncolliding labels.
- Add lane search, group-aware ordering and up to three sticky pins.
- Add runtime trace direction/kind/depth controls and shortest declared-path explanations.
- Add bounded undo/redo for view state, including viewport, selection, filters, lane/trace settings and scroll.
- Extend schema-1 saved views additively; unlimited depth serializes as null; old views remain supported.
- Add real three-browser acceptance tests, benchmark fixtures/results and release package validation.
- Add versioned GitHub release workflow and compatibility policy.

## 0.1.0

Initial generic Canvas2D timeline, interval query index, transfers, explicit event groups and causal trace, density cells, keyboard/list alternatives, PNG and saved-view export, Python adapter and separate private synthetic demo. Follow-up fixes hardened JSON inputs and added trace fitting and selection-preserving event focus.
